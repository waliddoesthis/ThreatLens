# ThreatLens

Ask about an alert, a log line or a CVE and get a cited answer grounded in MITRE ATT&CK, CISA KEV,
CERT-FR and SigmaHQ.

Code, benchmarks and design decisions: https://github.com/waliddoesthis/ThreatLens

This is a demo on free CPU hardware with a free hosted model: answers take a while, and the number
of questions per visit and per day is capped.
